# @tinyedge/pi-runtime namespace bootstrap

This intentionally inert package reserves the public npm namespace used by
TinyEdge's reviewed Pi compatibility runtime. Version `0.0.0` contains no
executable code, commands, dependencies, lifecycle scripts, or bundled files.

It is published only under the non-default `bootstrap` tag. The first real
runtime candidate is built, verified, and staged separately from the public
TinyEdge edge-client repository.
